# 脚本用法

所有脚本都在本技能资源目录的 `scripts/` 下；Node 18+，零第三方依赖，只用 node 内置模块和 CDP 的 HTTP/WS。

```bash
# Windows 找不到 node 时显式指定
export NODE_BIN="C:/Users/admin/.dsh/dsh-runtimes/dsh-primary-runtime/dependencies/node/bin/node.exe"
```

## 0. 前置：浏览器必须带调试端口

脚本不启动浏览器，只连 `http://127.0.0.1:9222`。Windows 双击 `scripts/start-qc.cmd`（Chrome/Edge 二选一，profile 放 `%USERPROFILE%\qc-chrome`）。

- **必须由用户自己启动**：沙箱内起 Chrome 会因为 crashpad/lockfile 无权限直接自杀。
- 启动后在该浏览器里登录千川；技能会用 `Target.createTarget` 自己开标签页，不需要手动摆好页面。

## 1. hourly.mjs —— 主入口

```bash
node hourly.mjs --doctor                  # 打印清单与生效规则，不碰页面
node hourly.mjs --once --dry-run          # 跑一轮，只判定不提交
node hourly.mjs --once                    # 跑一轮，命中就提交并回读日志
node hourly.mjs --once --account B        # 只跑某个账号
node hourly.mjs --watch                   # 按节点常驻（默认 :15/:30/:45/:55，共 8 轮）
```

参数：

| 参数 | 默认 | 说明 |
|---|---|---|
| `--once` / `--watch` | once | 跑一轮 / 按节点循环 |
| `--dry-run` | 关 | 只读不提交 |
| `--account <key>` | 全部 | 只跑某账号 |
| `--max-rounds <n>` | watch 时 8 | watch 跑几轮 |
| `--stage-timeout <s>` | 90 | 单阶段看门狗 |
| `--round-timeout <s>` | 420 | 整轮看门狗 |
| `--shots <dir>` | 数据目录 | 截图存放 |
| `--doctor` | — | 打印清单 |

一轮的步骤（都写进 `rounds.jsonl` 的 `stageMs`）：

1. 按账号分组，一账号一标签页（复用 URL 带 `aavid=` 的现成标签，没有就新开）；
2. 进列表（全域 `/uni-prom`、乘方 `/overall-prom?campaignType=1`），等 `hasAwemeCol && rows>0 && iconsReady`，超时强刷一次；
3. `statQuery` 拿当天每小时 × 每 ad 的分时数据；
4. 缺映射的 ad 跳详情页读页头补 `ad-map-<aavid>.json`；
5. 读行状态（是否在投放、是否已有控量），判 standby / controlling / not-live / no-spend / ROI；
6. 命中就 `control-lib.runControl` 提交，再跳详情页「日志」核对预算/时长/开始时间（±120 s）；
7. 写 `rounds.jsonl`、`actions.jsonl`、`errors.jsonl`，异常走通知。

退出码：0 正常（含本轮不控）；非 0 表示该轮出错（具体看 stdout 的 `stage`）。

## 2. control.mjs —— 单次控量

```bash
node control.mjs --aweme "抖音号名称" --budget 200 [--aavid 账户ID] [--dry-run] [--shots 目录]
```

不给 `--aavid` 时用当前标签页 URL 里的 `aavid`。退出码：0 成功/演练；2 定位失败；3 页面结构不符；4 状态不允许（未投放、已有控量、图标禁用）。

页面表达式都在 `scripts/expr/*.js`，用 `{{AWEME}}` / `{{BUDGET}}` / `{{ADV}}` 占位替换 —— 改选择器只动这些文件。

## 3. targets.mjs —— 清单

```bash
node targets.mjs accounts                                      # 账号列表
node targets.mjs account-add --key A --aavid 1860000000000001 --name "账户名" --entry uniprom
node targets.mjs account-add --key B --aavid 1860000000000002 --name "账户名" --entry square
node targets.mjs account-rm --key B                            # 有目标时会拒绝
node targets.mjs add --account A --name "抖音号名" --uid abc123 --ads 1860000000000003 --roi 2.4 --budget 200 --nodes 15,30,45,55
node targets.mjs list
node targets.mjs rm <id> | on <id> | off <id>
node targets.mjs standby <id>   # 同名抖音号由别的账号投放时，把它标为备用
node targets.mjs primary <id>
node targets.mjs doctor
```

## 4. notify.mjs —— 通知自检

```bash
node notify.mjs --test                                  # 用数据目录的 notify.json 发一条测试
node notify.mjs --title "标题" --text "内容"             # 手动发一条
```

配置见 `references/04-清单与通知.md` 与 `docs/notify.sample.json`。退出码 0 表示至少一个通道送达。

## 6. 故障速查

| 现象 | 原因 | 处理 |
|---|---|---|
| `fetch failed` / `ECONNREFUSED 9222` | 浏览器没开调试端口 | 双击 `start-qc.cmd`，别在沙箱里起 |
| 读不到「抖音号」列 | 落在详情页或另一条产品线 | 检查 `page.url`，用 `startsWith` 判定 |
| 点 + 没反应 | 该行已有控量 / 图标禁用 | 视为轮空，看行上是否 `iconPauseFilled` |
| 提交后弹窗不消失 | 复用旧坐标（起量态比控量态高约 150 px） | 已修：提交前当场重测按钮 |
| 切账号后还停在旧页面 | 千川是 SPA，`?aavid=` 只换账号不换路由 | 已修：切完账号点导航 + tab |
| 页面整体点不动 | 无关活动弹窗压着 | 先跑 `dismissOverlays`（业务弹窗会被跳过） |
| 日志核对不一致 | 提交没真正生效 | **不要重试提交**，先看 `actions.jsonl` 和页面 |

## 7. 调试单个表达式

```bash
node -e "import('./cdp-lib.mjs').then(async m=>{const p=await m.connect('jinritemai');console.log(await p.eval('document.title'));p.close()})"
```

`page.shot(path)` 存截图，`page.clickAt(x,y)` 发真实鼠标事件，`page.evalJson(expr)` 返回对象。
